# Hospital Management System

A simple menu-driven Hospital Management System developed using Python.

## Features
- Patient registration
- View all registered patients
- Search patient using patient ID
- View doctor details
- Book appointments
- View appointment records
- Calculate hospital bills

## Python concepts used
- Functions
- Conditional statements
- Loops
- Lists and dictionaries
- Modules and imports
- File handling using JSON

## Requirements
- Python 3.8 or later
- No external packages required

## How to run
1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Run:

```bash
python main.py
```

The program automatically creates a `data` folder to store patient and appointment records.

## Project note
This is an educational demonstration project. Do not use real patient or confidential medical information.
